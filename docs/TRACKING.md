# Слой отслеживания

Модуль:

```text
src/tracking/
```

Система слежения обеспечивает синхронизацию со спутниковыми сигналами.

Обработка данных с каждого спутника осуществляется по **каналу слежения**.

Циклы отслеживания:

| Цикл                      | Цель                                          |
| ------------------------- | --------------------------------------------- |
| DLL (Delay Lock Loop)     | Слежение за фазой псевдослучайного кода (PRN) |
| PLL (Phase Lock Loop)     | Слежение за фазой несущей                     |
| FLL (Frequency Lock Loop) | Слежение за частотой несущей                  |

Абстракция отслеживающего канала:

```text
TrackingChannel {
  prn
  dll
  pll
  fll
  state
  cn0_estimator
}
```

Несколько каналов работают параллельно.

Типичные приемники отслеживают **8–32 спутника одновременно**.
