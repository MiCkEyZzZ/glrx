# 7. Навигационный слой

Модуль:

```text
src/navigation/
```

Обязанности:

- декодирование навигационных кадров
- анализ эфемеридных данных
- извлечение параметров спутниковых часов
- вычисление положения спутников

Важные компоненты:

| Компонент       | Описание                             |
| --------------- | ------------------------------------ |
| FrameDecoder    | Синхронизация битов и субкадров      |
| EphemerisParser | Декодирование орбитальных параметров |
| NavData         | Спутниковое хранилище состояния      |

Навигационные данные позволяют вычислять положение спутника
для расчета псевдодальности.
